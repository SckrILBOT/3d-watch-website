# ТЗ 2. Подготовка сцены и экспорт в GLB

**Исполнитель:** ИИ-агент с доступом к Blender через Blender MCP
**Вход:** сцена из ТЗ 1
**Результат:** файл `watch_calibre.glb` в папке сайта

---

## Цель

Подготовить модель так, чтобы сайт мог раздвигать слои и вращать детали вокруг их собственных осей без поправок в коде.

## Требования

### 1. Трансформации

- У всех 10 объектов `Layer01…Layer10` применены масштаб и поворот: `scale = (1, 1, 1)`, `rotation = (0, 0, 0)`.
- У вращающихся деталей точка Origin стоит точно на оси вращения:
  `Layer03_MainspringBarrel`, `Layer04_GearTrain`, `Layer05_Escapement`, `Layer06_BalanceWheel`, `Layer08_Hands`.
  Иначе в Three.js деталь будет вращаться вокруг чужой точки.

### 2. Иерархия

- Пустой объект `Watch_Root` в точке (0, 0, 0).
- Все 10 слоёв — его дочерние объекты.

### 3. Экспорт

```python
bpy.ops.export_scene.gltf(
    filepath=".../watch_calibre.glb",
    export_format='GLB',
    export_apply=True,
    export_yup=True,
)
```

## Приёмка

- Файл открывается, в нём `Watch_Root` и 10 слоёв с исходными именами.
- Вращающиеся детали крутятся на месте вокруг своей оси.
- Учтено, что из-за `export_yup=True` ось сборки в glTF — Y, а не Z.
