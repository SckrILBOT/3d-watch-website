# ТЗ 1. 3D-модель часового механизма (Blender)

**Исполнитель:** ИИ-агент с доступом к Blender через Blender MCP
**Результат:** сцена Blender с моделью из 10 именованных слоёв, готовая к экспорту в GLB

---

## Роль

Ты — технический 3D-художник и Python-разработчик для Blender. Работаешь через Blender MCP: пишешь скрипты `bpy` и выполняешь их в открытой сцене.

## Контекст

Модель предназначена для интерактивного сайта на Three.js. На сайте часы разбираются при прокрутке (exploded view): слои расходятся вдоль одной оси, вращающиеся детали анимируются в реальном времени. Поэтому структура модели — имена, ось сборки, точки вращения — важнее художественных деталей: на неё опирается код сайта.

Объект — механические часы премиум-класса **CHRONOS CALIBRE-01**.

## Требования

### 1. Сцена и ось сборки

- Перед началом удалить объекты сцены по умолчанию (куб, свет, камера).
- Все детали соосны: центр в X = 0, Y = 0.
- Слои стоят друг над другом вдоль оси Z, снизу вверх, чтобы на сайте их можно было раздвигать вдоль одной оси.

### 2. Слои

Ровно 10 отдельных mesh-объектов с точными именами. Имена — контракт с кодом сайта, менять их нельзя.

| Имя объекта | Содержимое | Z |
|---|---|---|
| `Layer01_Caseback` | задняя крышка с прозрачным окном | −0.60 |
| `Layer02_Mainplate` | платина: основание механизма с вырезами | −0.40 |
| `Layer03_MainspringBarrel` | заводной барабан с зубчатым венцом и видимой пружиной; смещён от центра | −0.20 |
| `Layer04_GearTrain` | колёсная передача: 3–4 сцепленных колеса разного диаметра со спицами и зубьями | 0.00 |
| `Layer05_Escapement` | спусковое колесо со скошенными зубьями, анкерная вилка, рубиновые камни | 0.15 |
| `Layer06_BalanceWheel` | баланс с волосковой пружиной и мостом | 0.30 |
| `Layer07_SkeletonDial` | кольцо циферблата с часовыми метками и минутной дорожкой | 0.45 |
| `Layer08_Hands` | часовая, минутная и секундная стрелки | 0.60 |

### 3. Геометрия

- Без примитивных гладких цилиндров. Колёса генерируются программно: зубья, обод, спицы (через `bmesh` или расчёт вершин).
- Мелкие детали: винты, рубиновые камни в центрах осей.
- Фаски (`Bevel`, 2–3 сегмента) и `Shade Auto Smooth`, чтобы грани давали блики.

### 4. Материалы

Только Principled BSDF без процедурных нод (Noise, Voronoi и т. п.): процедурные ноды не экспортируются в glTF.

| Материал | Назначение | Параметры |
|---|---|---|
| `Mat_BrushedTitanium` | корпус, платина | Metallic 0.95, Roughness 0.25, тёмно-серый |
| `Mat_RoseGold` | основные колёса, баланс | Base Color (0.85, 0.55, 0.35), Metallic 1.0, Roughness 0.15 |
| `Mat_ChromeSteel` | стрелки, винты, спуск | Metallic 1.0, Roughness 0.08 |
| `Mat_RubyJewel` | камни | Base Color (0.9, 0.02, 0.15), Roughness 0.05, Transmission 0.8 |
| `Mat_SapphireGlass` | стекло | Base Color (0.9, 0.95, 1.0), Roughness 0.02, Metallic 0.1, Alpha 0.18, Blend Mode: Blend |

## Порядок работы

Строить пошагово, после каждого шага проверять сцену через MCP: объекты на месте, имена верные, геометрия без ошибок.

## Результат и приёмка

- В сцене ровно 10 объектов `Layer01…Layer10`, имена совпадают с таблицей.
- Слои соосны и стоят по оси Z в указанном порядке.
- Все материалы — Principled BSDF без процедурных нод.
- В конце — список объектов сцены и подтверждение готовности к экспорту.
