# ТЗ 3. Интерактивный 3D-сайт (Three.js + GSAP)

**Исполнитель:** ИИ-агент (Claude Code)
**Вход:** `watch_calibre.glb` из ТЗ 2
**Результат:** готовый к запуску статический сайт **CHRONOS // CALIBRE-01 — анатомия часового механизма**

---

## Цель

Презентация часового механизма, где прокрутка страницы рассказывает историю: часы разбираются слой за слоем, а камера показывает, как устроен механизм. Уровень визуала — сайты-лауреаты Awwwards.

## Стек

| | |
|---|---|
| Вёрстка | HTML, CSS: тёмная премиальная тема, матовое стекло (`backdrop-filter`), шрифты Cormorant Garamond, Space Grotesk, Inter; акценты — золото и титан |
| 3D | Three.js: `GLTFLoader`, `OrbitControls`, `RoomEnvironment` для бликов на металле, `EffectComposer` с лёгким `UnrealBloomPass` |
| Анимация | GSAP + ScrollTrigger |

## Функции

### 1. Живой механизм

В цикле `requestAnimationFrame` найти узлы модели по именам и анимировать:

- `Layer06_BalanceWheel` — гармонические колебания баланса;
- `Layer03_MainspringBarrel`, `Layer04_GearTrain`, `Layer05_Escapement` — вращение с разными передаточными скоростями;
- `Layer08_Hands` — стрелки показывают реальное время.

### 2. Разборка по прокрутке: 5 секций

Canvas закреплён на весь экран (`position: fixed`), поверх него прокручиваются секции с текстом и характеристиками.

| Секция | Что происходит |
|---|---|
| 1. Первый экран | часы собраны, контровый свет, заголовок |
| 2. Внешняя защита | стекло, корпус и крышка расходятся вдоль оси и открывают механизм |
| 3. Энергия и передача | камера приближается к барабану и колёсам, слои расходятся шире |
| 4. Сердце калибра | крупный план спуска и баланса, видна работа анкера и камней |
| 5. Свободный осмотр | прокрутка закончена, часы вращаются мышью, детали доступны по клику |

### 3. Панель управления внизу экрана

- **Рентген (X-Ray):** внешние детали становятся полупрозрачной сеткой, механизм остаётся непрозрачным.
- **Степень разборки:** ползунок 0–100 % вручную раздвигает и собирает слои.
- **Скорость механизма:** 0.2×, 1×, 10× и пауза.
- **Узлы:** четыре точки (барабан, колёсная передача, спуск, баланс). По клику камера летит к детали и открывается карточка с характеристиками: 28 800 полуколебаний в час, 72 часа хода, 29 камней.

### 4. Надёжность

- Экран загрузки с процентами.
- Если имена слоёв в GLB не совпадают с ожидаемыми, вывести в консоль найденные узлы и распределить их по высоте, чтобы разборка всё равно работала.

## Результат и приёмка

- Полный код проекта, запускается локальным статическим сервером.
- Все 10 слоёв найдены, механизм анимирован, разборка идёт по прокрутке вперёд и назад.
- Каждая кнопка панели делает то, что обещает.
- Сайт проверен в браузере после запуска.
